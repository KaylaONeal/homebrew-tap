# Homebrew tap

The maintained Homebrew tap for [InputPin](https://github.com/KaylaONeal/InputPin), a native macOS input-source pinning utility.

After a stable release is published, install with:

```sh
brew install --cask kaylaoneal/tap/inputpin
```

The cask downloads an exact Developer ID signed, notarized release and verifies its SHA-256. It supports Apple Silicon and Intel on macOS Ventura or later. This is a custom tap, separate from Homebrew's official catalog.

Cask contributions should keep a fixed version, verified upstream URL and real checksum. Run Homebrew style and audit checks before changing a cask. Report app bugs in the InputPin repository. MIT licensed.
